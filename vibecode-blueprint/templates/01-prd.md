# PRD — Documento de Requisitos do Produto

## Resumo do app
Uma frase descrevendo o que o app faz e para quem.

## Problema que resolve
O que o usuário não consegue fazer hoje, ou faz de forma ruim, que este app resolve.

## Público-alvo
Quem vai usar. Se houver mais de um tipo de usuário (exemplo: cliente e administrador), liste cada um separado.

## Funcionalidades da primeira versão
Lista das funcionalidades que entram na primeira versão construída. Cada item com uma descrição curta do que faz, não só o nome.

1. Funcionalidade — o que faz
2. Funcionalidade — o que faz

## Fora do escopo da primeira versão
O que foi considerado e decidido deixar para depois. Existe para impedir que o agente de código "adicione de bônus" algo que não foi pedido.

## Critério de sucesso
Como saber se a primeira versão está pronta e funcionando como esperado.
